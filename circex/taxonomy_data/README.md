# Vendored time-domain taxonomy

The YAML files here are vendored from
[skyportal/timedomain-taxonomy](https://github.com/skyportal/timedomain-taxonomy)
(MIT License, Copyright (c) 2020 Joshua Bloom — see `LICENSE.timedomain-taxonomy`),
so a pip-installed `circex` can validate classifications without an external
clone. Override with the `CIRCEX_TAXONOMY_DIR` env var to use a different copy.
